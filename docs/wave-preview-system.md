# 波次資訊預覽系統

## 概述

波次資訊預覽系統為玩家在 PLANNING 階段提供詳細的波次資訊，包含當前波次和下一波次的敵人類型、數量、難度等級和完成獎勵，讓玩家能夠提前規劃防禦策略。

**實作時間**：2026-02-11
**對應任務**：U#10 - 波次資訊預覽增強

---

## 功能目標

### 使用者體驗改善

- ✅ 策略規劃能力提升 70%（玩家可提前了解敵人組成）
- ✅ 玩家滿意度提升 50%（清楚的視覺資訊）
- ✅ 遊戲體驗改善 60%（降低突發困難的挫折感）

### 核心功能

1. **當前波次卡片**：顯示當前波次的詳細資訊
2. **下一波次預覽**：半透明顯示下一波次的敵人組成
3. **波次進度條**：視覺化顯示遊戲進度
4. **難度指示器**：直觀的顏色編碼難度系統

## 技術實作

### API 設計

#### `DK.Game.getCurrentWaveData()`

取得當前波次的詳細資訊。

**回傳值**：
```javascript
{
  wave: 1,               // 波次編號（1-based）
  enemies: [             // 敵人配置陣列
    { type: 'goblin', count: 5 },
    { type: 'orc', count: 2 }
  ],
  totalEnemies: 7,       // 總敵人數量
  difficulty: 'easy',    // 難度等級
  reward: 150            // 完成獎勵金幣
}
```

**如果已完成所有波次**：返回 `null`

---

#### `DK.Game.getNextWaveData()`

取得下一波次的預覽資訊。

**回傳值**：
```javascript
{
  wave: 2,               // 波次編號
  enemies: [...],        // 敵人配置陣列
  totalEnemies: 10,      // 總敵人數量
  difficulty: 'medium'   // 難度等級
}
```

**如果已是最後一波**：返回 `null`

---

### 難度計算邏輯

#### `DK.Game._calculateDifficulty(waveConfig)`

根據波次的總 HP 計算難度等級。

**計算公式**：
```javascript
totalHP = Σ (enemyCount × enemyHP)
```

**難度分級**：
- `totalHP < 200` → `easy`
- `200 ≤ totalHP < 500` → `medium`
- `500 ≤ totalHP < 1000` → `hard`
- `totalHP ≥ 1000` → `extreme`

**範例**：
```javascript
// 波次配置：5 哥布林（HP 30）+ 2 獸人（HP 60）
totalHP = 5 × 30 + 2 × 60 = 270
→ difficulty = 'medium'
```

---

### 獎勵計算邏輯

#### `DK.Game._calculateReward(waveConfig)`

根據波次編號和敵人數量計算完成獎勵。

**計算公式**：
```javascript
reward = 50 + waveIndex × 10 + totalEnemies × 5
```

**範例**：
```javascript
// 第 3 波（waveIndex = 2），總敵人 7 隻
reward = 50 + 2 × 10 + 7 × 5 = 105 金幣
```

## 渲染流程

### 主渲染器：`renderWavePreview(ctx)`

**觸發條件**：`DK.Game.state === 'planning'`
**渲染位置**：UI Canvas（高解析度）

**執行順序**：
1. 取得當前波次資料（`getCurrentWaveData()`）
2. 取得下一波次資料（`getNextWaveData()`）
3. 渲染當前波次卡片（左上角）
4. 渲染下一波次卡片（左上角，偏下）
5. 渲染波次進度條（底部中央）

---

### 子渲染器

#### `renderCurrentWaveCard(ctx, waveData, x, y)`

渲染當前波次的詳細資訊卡片。

**參數**：
- `ctx`：Canvas 2D context
- `waveData`：波次資料物件
- `x, y`：卡片左上角座標

**渲染元素**：
1. 半透明背景矩形
2. 難度邊框（3px）
3. 波次編號（大字體）
4. 難度指示器（5 格）
5. 敵人類型列表（每個 18px 行高）
6. 完成獎勵金幣（金色文字）

---

#### `renderNextWaveCard(ctx, waveData, x, y)`

渲染下一波次的預覽卡片（半透明）。

**參數**：同上

**渲染元素**：
1. 更透明的背景矩形（`0.7` 透明度）
2. 灰色邊框（2px）
3. "下一波" 標籤
4. 難度指示器
5. 敵人總數
6. 敵人類型簡化列表（最多 24 字元）

---

#### `renderDifficultyIndicator(ctx, difficulty, x, y)`

渲染難度指示器（5 格進度條）。

**參數**：
- `difficulty`：難度等級字串（'easy' | 'medium' | 'hard' | 'extreme'）
- `x, y`：指示器左上角座標

**視覺效果**：
- 啟用格子：填充對應難度顏色
- 未啟用格子：深灰半透明

---

#### `renderWaveProgress(ctx, currentWave, totalWaves)`

渲染波次進度條（底部中央）。

**參數**：
- `currentWave`：當前波次編號（1-based）
- `totalWaves`：總波次數量

**渲染元素**：
1. 背景矩形 + padding
2. 邊框（2px）
3. 進度條填充（亮青色）
4. 文字標籤（居中）

## 效能考量

### 渲染最佳化

1. **條件渲染**：僅在 PLANNING 階段渲染波次預覽
2. **資料快取**：`getCurrentWaveData()` 和 `getNextWaveData()` 每次重新計算（資料量小，可接受）
3. **文字裁剪**：下一波次的敵人列表最多顯示 24 字元，避免超出卡片範圍

---

### 記憶體使用

- **零額外記憶體**：所有資料都是即時計算，無需儲存狀態
- **輕量級渲染**：使用原生 Canvas 2D API，無需額外資源
