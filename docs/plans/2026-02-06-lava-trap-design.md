# 段落 1：核心機制

## 熔岩地磚（L）
- 新的地磚類型，外觀為流動的熔岩深淵，帶有脈動發光動畫
- 不可通行 — 怪物的 BFS 尋路會繞過它（跟牆壁一樣）
- 放在路徑旁邊，替換部分原本的牆壁磚
- 怪物被推進去 = 秒殺，播放沉入熔岩的死亡動畫

## 推力陷阱（牆壁型）
- 安裝在牆壁上，面朝相鄰的路徑
- 定時自動觸發，每 3 秒推一次，有明顯的「蓄力→推出」動畫讓玩家可以預判
- 觸發時，將面前路徑格上的所有敵人往前推 1 格
- 如果推出去的那格是熔岩 → 秒殺；如果是普通地板 → 只是位移，不造成傷害
- 佈局核心：牆壁（推力陷阱）→ 路徑（怪物走這）→ 熔岩（掉下去）

## 質量系統

| 怪物   | 質量     | 推力結果                         |
|--------|----------|----------------------------------|
| 哥布林 | 1（輕）  | 直接推飛                         |
| 史萊姆 | 1（輕）  | 直接推飛                         |
| 骷髏   | 2（中）  | 可以推動                         |
| 獸人   | 3（重）  | 推不動，原地抵抗（晃動動畫）     |

推力陷阱基礎推力 = 2，所以能推動哥布林、史萊姆、骷髏，但推不動獸人。
