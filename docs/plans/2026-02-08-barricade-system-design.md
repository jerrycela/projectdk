# 路障系統設計

## 概述
玩家在破牆後可放置可摧毀的石磚路障在路徑格上，改變怪物的 BFS 尋路結果，迫使怪物繞道經過陷阱區。所有路徑被封死時，怪物攻擊最短路線上的路障。

## 核心行為
- 路障放在路徑格（`. P G`），對 BFS 視為牆壁
- 存在繞道路線 → 怪物繞道，完全無視路障
- 所有路線被封死 → 怪物走 distanceFieldThrough 到最近路障，停下攻擊
- 路障有 HP，被攻擊歸零時碎裂消失，距離場即時重算

## 雙距離場架構
| 距離場 | 路障視為 | 用途 |
|--------|---------|------|
| `distanceField` | 牆壁 | 正常導航 |
| `distanceFieldThrough` | 可行走 | 封路時導航到路障 |

## 路障資料結構
```javascript
{ id, col, row, hp: 100, maxHp: 100 }
```
- 存放：`DK.Map.barricades = []`
- 上限：5 個（`DK.CONFIG.BARRICADE_MAX`）

## 放置規則
- 僅 breach 階段可放置（破牆後、入侵前）
- 可行走格（`. P G`），不可放在 `H A O B W`
- 不可與陷阱、英雄重疊
- 再次點擊同位置可移除（退回配額）

## 怪物攻擊路障
- 怪物 distanceField[pos] === -1 時切換 distanceFieldThrough
- 到達路障相鄰格停下攻擊
- 傷害 = heartDamage/秒（哥布林 10、骷髏 15、獸人 25、史萊姆 5）
- 路障 HP 歸零 → 碎裂 → 重算距離場

## 路徑預覽
- 破牆後常駐顯示虛線
- 從洞口沿距離場回溯到地心
- 正常路段：半透明紅色虛線
- 經過路障路段：半透明橙色虛線
- 放置/移除路障時即時更新

## 像素外觀
- 石磚柵欄：底部 10px 石牆 + 2px 深色邊緣
- 左上光源：左/上淺色，右/下深色
- 受擊晃動 1px、HP<50% 裂痕、HP<25% 碎石掉落
- 碎裂：4-6 石磚碎片飛散 400ms

## 遊戲流程
```
planning → breach（破牆 + 放路障 + 路徑預覽）→ invasion
```

## 修改範圍
| 檔案 | 內容 |
|------|------|

| game.js | barricade 受擊更新、碎裂處理 |
| enemies.js | 封路導航分支、攻擊路障行為 |
| ui.js | 路障按鈕、放置模式、懸停預覽 |
| main.js | 路障渲染、HP 條、虛線路徑預覽、碎裂特效 |
