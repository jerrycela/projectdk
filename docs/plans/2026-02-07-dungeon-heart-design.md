# Dungeon Heart 機制設計

## 概述

將固定入口/出口的蛇形路徑塔防，改為以「地心（Dungeon Heart）」為核心的開放式地城防守遊戲。玩家透過破壞外牆控制敵人入侵路線，敵人沿 BFS 最短路徑朝地心前進。

## 地圖結構

地圖分為三個區域：

### 1. 外圍區域（Outer Ring）— 2 格寬
- 地圖最外圈 2 排/列，敵人在此巡邏
- 地磚類型 `O`（outer），視覺呈現為野外/森林/荒野
- 玩家可見但不可放置陷阱

### 2. 外牆（Outer Wall）— 1 格寬
- 地圖第 3 排/列，環繞整個地城
- `B`（breakable wall）= 可破壞牆壁
- `W` = 不可破壞的結構牆（角落等）
- 玩家點擊 `B` 打洞 → 變成路徑 `.` → 成為敵人入口

### 3. 地城內部（Dungeon Interior）
- 約 34×20 的開放空間
- 開放式房間+走廊佈局
- 地磚：`.` 地板、`W` 內牆、`A` 深淵、`P` 水潭、`G` 草叢
- `H` = 地心（Dungeon Heart），固定在中央區域

## 關卡流程（三階段）

### 階段 1：規劃期（Planning Phase）
- 顯示完整地圖，含外圍區域
- 敵人在外圍巡邏（顯示本波次敵人類型與數量）
- 玩家可放置/升級陷阱、部署英雄法師
- 無時間限制
- UI 底部顯示「開始破牆」按鈕

### 階段 2：破牆期（Breach Phase）
- 外牆 `B` 格高亮可點擊
- 點擊 `B` → 破碎動畫 → 變成路徑 `.`
- 即時顯示 BFS 路徑預覽（半透明箭頭）
- 可開 1～多個洞，免費永久
- 最少 1 洞才能繼續
- UI 底部顯示「開始入侵」按鈕

### 階段 3：入侵期（Invasion Phase）
- 所有波次自動連續進行
- 敵人從各洞口湧入，沿 BFS 路徑朝地心前進
- 波次間隔：上一波清除後 3 秒自動開始
- 玩家可即時放陷阱、移動英雄
- 不可再破牆
- 通關條件：所有波次清除 = 勝利；地心 HP 歸零 = 失敗

## 地心（Dungeon Heart）

### 基本屬性
- 佔據 2×2 格，`H` 標記左上角
- 初始 HP：100
- 不可移動、不可被玩家互動

### 受傷機制
- 敵人到達地心相鄰格時攻擊
- 傷害依敵人類型：哥布林 10、骷髏 15、獸人 25、史萊姆 5（留減速區域）
- 攻擊後敵人消失
- HP 歸零 → 遊戲結束

### 視覺設計
- 發光水晶/心臟，32×32 像素
- 脈動光暈動畫（週期 2000ms）
- 受傷時閃紅 + 螢幕震動
- HP < 30% 時光暈變暗、脈動加速
- HP 條顯示在上方

## 敵人路徑與生成系統

### BFS 動態路徑
- 以地心為終點做 BFS，建立距離場（distance map）
- 每格記錄到地心最短步數
- 敵人每幀走向數值更小的鄰格
- 破牆後重新計算一次距離場

### 多入口生成分配
- 每波敵人均勻分配到所有洞口
- 各洞口獨立生成計時器
- 微小隨機延遲（0-300ms）避免同步

### 外圍巡邏
- 規劃期顯示本波次敵人剪影/半透明版本
- 順時針沿外牆緩慢巡邏
- 入侵期後消失

## 技術實作

### 檔案影響範圍
| 檔案 | 改動 | 說明 |
|------|------|------|
| config.js | 中 | 新增常數 |
| map.js | 大 | 新地圖、新地磚、距離場 BFS、破牆 |
| game.js | 大 | 三階段 state、地心 HP、自動波次、多入口生成 |
| enemies.js | 中 | 距離場移動、地心攻擊 |
| ui.js | 大 | 按鈕、破牆互動、路徑預覽、地心 HP 條 |
| main.js | 中 | 地心渲染、破牆動畫、路徑預覽 |
| heroes.js | 小 | 巡邏範圍限制 |
| traps.js | 小 | 放置限制 |
| pixelart.js | 小 | 新像素繪製函式 |
| elements.js | 無 | 不需改動 |

### 實作順序
1. config + map（新地圖 + 地磚 + 距離場）
2. game（三階段 + 地心 HP + 自動波次）
3. enemies（距離場移動 + 地心攻擊）
4. ui + main（按鈕 + 破牆互動 + 渲染）
5. heroes + traps（範圍限制微調）
