# 英雄系統 + 元素反應機制 — MVP 設計

## 概述

為地層塔防新增可部署、可移動的英雄單位，並引入元素反應系統讓英雄與陷阱協同作戰。MVP 聚焦於驗證核心機制的手感與視覺表現。

## MVP 範圍

### 水法師英雄
- 部署在地板格子上，花費 80g
- 點擊英雄 → 點擊目標地板格 → BFS 尋路自動移動
- 射程 3 格，攻擊間隔 1.5 秒
- 水彈命中附加「潮濕」狀態（持續 3-4 秒）
- 潮濕本身不造成額外傷害，藍色水滴粒子標記

### 電擊板陷阱（新）
- 地板型陷阱，對踩上的敵人造成電系傷害
- 對「潮濕」敵人觸發感電反應

### 感電元素反應（潮濕 + 電）
- 麻痺 2 秒（敵人停止移動）
- 觸電 DoT（持續 2 秒額外傷害）
- 反應後消耗「潮濕」狀態

### 視覺爽快感設計
- 觸發瞬間：畫面震動 2-3 幀、白色閃光、閃電鏈特效、電弧粒子擴散、大號黃白閃爍傷害數字、「感電！」文字浮出
- 持續階段：敵人凍結、小電弧環繞、sprite 閃爍抽搐、每跳 DoT 小傷害數字
- 結束：電弧爆散、恢復移動
- 連鎖閃電：多隻敵人同時感電時電弧在敵人間跳動

### 測試調整
- 起始金幣大幅增加（測試用）

### 不包含在 MVP
- 帳號等級系統
- Cost 陣容構築系統
- 多英雄
- 其他元素種類
- 稀有度系統
