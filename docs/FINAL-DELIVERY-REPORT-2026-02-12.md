### Phase 2：視覺優化系統（固定 DW3 風格）

#### 3. 視覺設定系統 ✅
- **檔案**：`js/config.js`
- **設計理念**：Dungeon Warfare 3 —— 「在黑暗地牢中，只看見重要的東西」
- **實作方式**：固定使用 DW3 風格參數（不提供模式選擇）
- **驗證**：所有參數符合 DW3 六大設計原則

**DK.VISUAL_SETTINGS 參數**：
```javascript
{
  // 環境光效
  vignette: true,              // 暈影（強度 0.6，降低 40%）
  ambientOcclusion: false,     // 環境光遮蔽（關閉）

  // 動畫效果（核心元素保留）
  torchFlicker: true,          // 火把閃爍
  puddleAnimation: true,       // 水潭波紋
  portalSwirl: true,           // 傳送門漩渦
  heartPulse: true,            // 地心脈動
  grassAnimation: true,        // 草叢動畫
  abyssAnimation: true,        // 深淵動畫

  // 粒子系統
  particleEffects: true,
  particleDensity: 0.7,        // 降低 30%（避免雜亂）

  // 後處理效果
  bloomEffect: false,          // 光暈（關閉，避免過度發光）
  colorGrading: true,          // 色調調整（保留）

  // 進階渲染
  gradientLighting: true,
  smoothShading: false,        // 關閉（效能成本高）
  detailTextures: true,

  // 特效強度（體現 DW3 降低 40-50% 理念）
  glowIntensity: 0.5,          // ↓50%
  shadowIntensity: 0.6,        // ↓40%
  vignetteIntensity: 0.6,      // ↓40%
  warmOverlayIntensity: 0.5,   // ↓50%
}
```
