# 關卡編輯器增強計畫
> 靈感來源：Dungeon Keeper、Dungeon Warfare 3

## 當前問題診斷

### 視覺問題
- ❌ 傳送門樣式不明顯（小綠點，不夠吸睛）
- ❌ 地城之心在編輯器和遊戲內顯示不一致
- ❌ 缺乏視覺層次和細節

### 功能問題
- ❌ 地磚種類雖多但缺乏系統性分類
- ❌ 沒有房間/區域系統
- ❌ 沒有陷阱預覽和配置
- ❌ 沒有圖層管理

### UX 問題
- ❌ 工具欄雜亂（18 種地磚全部列在一起）
- ❌ 沒有小地圖預覽
- ❌ 沒有快速導航
- ❌ 沒有網格對齊輔助

---

## 改進方案

### Phase 1: 視覺大幅強化 🎨

#### 1.1 傳送門視覺重設計
**靈感**：Dungeon Keeper 的入口（Portal）
- 改為 **2×2 大型漩渦**（更顯眼）
- 加入**脈動動畫**（編輯器中用多層漸變模擬）
- 區分**入口（綠色）**和**出口（紅色）**
- 加入**能量粒子效果**

#### 1.2 地城之心視覺統一
**靈感**：Dungeon Keeper 的 Dungeon Heart
- 確保編輯器使用 `drawHeartTile()` 一致渲染
- 加強發光效果（紫色脈動）
- 2×2 方塊組合顯示
- 加入邊框高亮

#### 1.3 增加地磚細節變體
- 每種地磚 3-6 個變體（自動隨機）
- 地板：裂縫、血跡、灰塵
- 牆壁：磚塊、岩石、鐵壁
- 裝飾：火把、骨頭、寶箱更精緻

---

### Phase 2: 功能擴展 - 房間系統 🏛️

**靈感**：Dungeon Keeper 的房間建造系統

#### 2.1 房間類型
| 房間 | 符號 | 功能 | 視覺風格 |
|------|------|------|----------|
| 寶庫 (Treasury) | $ | 儲存金幣 | 金色地板 + 寶箱堆 |
| 訓練室 (Training) | ⚔ | 訓練怪物 | 武器架 + 標靶 |
| 圖書館 (Library) | 📚 | 研究魔法 | 書架 + 卷軸 |
| 孵化場 (Hatchery) | 🥚 | 生產怪物 | 巢穴 + 蛋 |
| 牢房 (Prison) | 🔒 | 關押敵人 | 鐵籠 + 鎖鏈 |
| 墓地 (Graveyard) | ⚰️ | 復活亡靈 | 墓碑 + 骷髏 |

#### 2.2 房間放置邏輯
- 拖拉框選建立房間區域
- 自動生成房間邊界
- 顯示房間容量和狀態

### Phase 4: UX 大幅改善 🎯

#### 4.1 分類工具欄
**靈感**：Photoshop 的工具面板

```
📦 基礎地形
  ├─ 牆壁 (W)
  ├─ 地板 (.)
  ├─ 外圍 (O)
  └─ 深淵 (A)

🏰 房間與設施
  ├─ 地城之心 (H)
  ├─ 寶庫 ($)
  ├─ 訓練室 (⚔)
  └─ 圖書館 (📚)

🚪 傳送與路徑
  ├─ 入口傳送門 (E)
  ├─ 出口傳送門 (X)
  └─ 門 (D)

⚙️ 陷阱
  ├─ 尖刺 (▲)
  ├─ 箭塔 (🏹)
  └─ 火焰 (🔥)

🎨 裝飾
  ├─ 火把 (T)
  ├─ 寶箱 (C)
  ├─ 骸骨 (S)
  └─ 水晶 (X)

🌊 地形特殊
  ├─ 水潭 (P)
  ├─ 草叢 (G)
  └─ 熔岩 (L)
```

#### 4.2 小地圖預覽
- 右上角顯示整體地圖
- 顯示當前視野範圍
- 點擊快速導航

#### 4.3 圖層管理
- 地板層（基礎地形）
- 物件層（陷阱、房間）
- 裝飾層（火把、寶箱）
- 路徑層（顯示敵人路徑）

#### 4.4 快捷操作
- Tab：切換圖層
- Space + 拖拽：平移視野
- Ctrl + 滾輪：縮放
- Shift + 拖拽：框選複製
- Alt + 點擊：吸管工具

## 技術實作筆記

### 傳送門重設計
```javascript
// 2×2 漩渦效果
drawPortalTile(ctx, x, y, type) {
  // type: 'entrance' | 'exit'
  const color = type === 'entrance' ? '#44aa44' : '#aa4444';

  // 繪製 4 格漩渦
  for (let dy = 0; dy < 2; dy++) {
    for (let dx = 0; dx < 2; dx++) {
      drawSwirlEffect(ctx, x + dx*16, y + dy*16, color);
    }
  }
}
```
