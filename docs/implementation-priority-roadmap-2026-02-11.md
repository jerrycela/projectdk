### 1.6 雙擊陷阱快速升級 ⭐⭐⭐⚪⚪

**工作量**: 0.5 天

#### 技術實作

```javascript
// ui.js - 追蹤點擊時間
let lastClickTrap = null;
let lastClickTime = 0;

handleClick(mx, my) {
  const clickedTrap = DK.Traps.getTrapAt(col, row);
  if (clickedTrap) {
    const now = Date.now();
    if (clickedTrap === lastClickTrap && now - lastClickTime < 300) {
      // 雙擊升級
      const evo = DK.Traps.getEvolutionForTrap(clickedTrap);
      if (evo && DK.Game.gold >= evo.cost) {
        DK.Game.gold -= evo.cost;
        DK.Traps.evolveTrap(clickedTrap, evo.id);
      }
    }
    lastClickTrap = clickedTrap;
    lastClickTime = now;
  }
}
```

- 罕見組合標記: "你用了一種罕見組合:火焰軌道 + 油坑"
- 一鍵生成分享文案

---

### 3.2 陷阱圖鑑 + 皮膚系統 (5 天)

**功能**: 收集所有陷阱組合,解鎖特殊皮膚

**系統設計**:
- 圖鑑頁面顯示所有陷阱與組合
- 已使用 vs 未使用
- 解鎖成就獲得皮膚 (視覺變化,不影響屬性)

---

### 3.3 挑戰模式 + 每日挑戰 (4 天)

**功能**: 特殊規則的挑戰關卡

**挑戰類型**:
- 限定金幣: 只有 100 金幣通關
- 禁用陷阱: 不能使用火系陷阱
- 極速挑戰: 5 分鐘內通關
- 每日隨機挑戰: 每天一個新挑戰

---

### 3.4 排行榜 + 成就系統 (3 天)

**功能**: 競爭性與收集性系統

**排行榜類型**:
- 最少陷阱通關
- 最快通關
- 最高連擊

**成就範例**:
- 全程無傷
- 只用火系陷阱
- 擊殺 1000 隻敵人

---

### 3.5 可及性選項 (2 天)

**功能**: 讓更多玩家能享受遊戲

**選項**:
- 色盲模式: 圖示輔助
- 慢速模式: 敵人速度 ×0.5
- 放置輔助: 磁吸格子
- 音效輔助: 關鍵事件音效

---

### 3.6 陷阱組合推薦系統 (4 天)

### 3.7 重播模式 (5 天)

**功能**: 重播戰鬥過程,優化策略

**實作**: 事件記錄 + 播放器

## 總結
