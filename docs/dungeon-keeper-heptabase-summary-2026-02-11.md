## 概述

ProjectDK 完成 Dungeon Keeper 經典風格等距視覺增強專案，將地城之心、傳送門、木門從平面設計升級為具有立體感的等距 3D 風格。經過 2 次迭代優化，達到專業品質標準（DK 風格符合度 9.9/10，技術品質 9.9/10，性能預算僅佔 7.3%）。

## 核心成就

### 等距光影工具系統

創建完整的三層光影工具（Isometric 命名空間）：

- **topLight(+50)**: 頂面光照，最亮表面
- **sideDark(-40)**: 側面暗部，中等暗度
- **ambientOcclusion(-60)**: 環境光遮蔽，最暗區域（角落、縫隙）

所有元素遵循統一的 45° 偽等距視角 + 右上光源設定。

### 地城之心等距立體化

實作四大視覺系統：

1. **懸浮水晶效果**
   - 3px 空隙（水晶底部 vs 石座頂部）
   - 四層切面漸層（8×8 → 6×12 → 4×8 → 2×2）
   - 完美幾何遞減（符合鑽石原理）

2. **等距石座**
   - 三層遞減結構（14×6 → 12×4 → 10×3）
   - 右側暗邊（1px ambientOcclusion）
   - 緊湊型設計（更符合懸浮概念）

3. **彩色魔法投影**
   - 使用水晶顏色而非傳統黑色
   - 產生「魔法能量輻射」效果
   - 創新設計區別於物理陰影

4. **動態效果保留**
   - 內部白色光點脈動（2-4px, 0.6s 週期）
   - 地磚級光暈（3.5 格半徑）
   - HP 血條、受傷閃爍完整保留

### 傳送門深度化

實作三層深度系統：

1. **地面凹陷邊緣**（四邊等距光影）
   - 上邊：topLight（最亮，面向光源）
   - 左邊：sideDark（暗，背光面）
   - 右邊：lighten +10（中亮）
   - 下邊：darken -20（最暗）

2. **三層深度漩渦**
   - 深層：60% 縮放, alpha 0.4, Y+2px
   - 中層：80% 縮放, alpha 0.7, Y+1px
   - 表層：100% 縮放, alpha 1.0, Y+0px
   - 透過 scale + offset + alpha 模擬立體深度

### 木門等距立體化

實作三層結構：

1. **等距門框**（2px 厚度，深灰石材）
   - 頂部：topLight + 原色
   - 左側：sideDark
   - 右側：lighten +10
   - 底部：darken -20

2. **門板斜面**
   - 左上邊緣：topLight（1px 高光）
   - 右下邊緣：sideDark（1px 陰影）
   - 產生明顯斜面效果

3. **木紋凹陷**
   - 三條橫條使用 ambientOcclusion
   - 產生「雕刻」而非「塗色」效果

### 視覺層次設計

**三層視覺權重**:
1. **地城之心**（核心焦點）- 2×2 格，光影對比 ★★★★★，雙重動畫，高飽和度紫色
2. **傳送門**（功能焦點）- 2×2 格，光影對比 ★★★★☆，雙重動畫，中高飽和度綠色
3. **木門**（背景元素）- 1×1 格，光影對比 ★★★☆☆，靜態，中低飽和度褐色

**色彩和諧度**:
- 紫色（地心）← 互補對比 → 綠色（傳送門）
- 低飽和度深紫石座、土黃邊緣作為配角
- 褐色/灰色（門、地面）作為中性背景
