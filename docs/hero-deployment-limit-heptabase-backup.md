## 功能概述

成功實作英雄部署限制系統，確保每個英雄類型（水法師/火法師）只能部署一隻，增加遊戲策略深度。

### 核心功能

- ✅ 限制每個英雄類型只能部署一隻
- ✅ 嘗試重複部署時顯示錯誤訊息「該英雄類型已經部署了」
- ✅ 已部署的英雄按鈕顯示為 disabled 狀態
- ✅ 回收英雄後按鈕恢復可用狀態

## 實作細節

### 檔案修改清單

1. **js/heroes.js** - 部署邏輯修改
   - 在 deploy() 方法中新增同類型檢查
   - 使用 Array.some() 檢查是否存在相同類型且存活的英雄
   - 如果存在，顯示錯誤訊息並返回 false

2. **js/ui.js** - 按鈕狀態判定修改
   - 在 getButtonState() 方法中新增已部署狀態檢查
   - 已部署的英雄按鈕返回 DISABLED 狀態
   - UI 自動渲染為灰色不可點擊

3. **js/error-handler.js** - 錯誤訊息定義
   - 新增 hero_already_deployed 錯誤類型
   - 錯誤訊息：「該英雄類型已經部署了」
   - 可操作建議：「每個英雄類型只能部署一隻，請召回現有英雄後再部署」

## 核心實作邏輯

### 同類型檢查邏輯
```javascript
const sameTypeExists = this.active.some(h =>
  h.type.id === heroTypeId && h.alive
);
```

**關鍵點**：
- 使用 h.type.id 比對而非物件比較（更可靠）
- 檢查 h.alive 狀態（已死亡的英雄不應阻止部署）
- 使用 Array.some() 提升效能（找到第一個匹配即返回）

### UI 狀態更新時機

按鈕狀態在以下時機自動更新：
1. 每次渲染時（getButtonState() 被調用）
2. 部署英雄後（deploy() 返回後，UI 重繪）
3. 回收英雄後（recall() 執行後，UI 重繪）

**無需手動觸發更新**，遊戲循環會自動處理。
