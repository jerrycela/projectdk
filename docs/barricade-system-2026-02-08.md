# ProjectDK 路障系統實作完成

## 概述
完成地層塔防遊戲的路障系統（Barricade System），玩家可在破牆階段放置可摧毀的石磚路障改變怪物尋路路徑，採用雙 BFS 距離場架構實現智慧導航。

## 核心機制

### 雙距離場架構
- **distanceField**：路障視為牆壁，用於正常導航（怪物繞道）
- **distanceFieldThrough**：路障視為可行走，用於封路時導航到最近路障

### 怪物三態導航
1. **正常模式**：使用 distanceField，自動繞過路障
2. **封鎖模式**：所有路徑被封死時，使用 distanceFieldThrough 走向最近路障並攻擊
3. **抵達模式**：兩種距離場都檢查是否到達地城之心

### 放置規則
- 僅 breach 階段可放置（破牆後、入侵前）
- 上限 5 個，可行走格（. P G）
- 再次點擊移除（退回配額）

### 像素外觀
- 石磚柵欄底座 + 灰縫 + 左上光源
- 受擊晃動、HP<50% 裂痕、HP<25% 碎石
- 碎裂特效：4-6 石磚碎片飛散 400ms

### 路徑預覽
- 破牆後常駐虛線從洞口到地心
- 正常路段紅色、經路障路段橙色
- 放置/移除路障即時更新
