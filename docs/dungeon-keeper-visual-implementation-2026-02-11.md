### 任務 #1：等距光影工具

**實作位置**：`/js/pixelart.js` 行 340-375

**實作內容**：

```javascript
DK.PixelArt.Isometric = {
  // 頂面光照（最亮，+50）
  topLight(baseColor, amount = 50) {
    return DK.PixelArt.lighten(baseColor, amount);
  },

  // 側面暗部（中暗，-40）
  sideDark(baseColor, amount = 40) {
    return DK.PixelArt.darken(baseColor, amount);
  },

  // 環境遮蔽（最暗，-60，用於角落/縫隙）
  ambientOcclusion(baseColor, amount = 60) {
    return DK.PixelArt.darken(baseColor, amount);
  },
};
```

**技術亮點**：
- ✅ 獨立的 `Isometric` 命名空間，清晰易用
- ✅ 基於現有 `lighten()` 和 `darken()` 方法，避免重複程式碼
- ✅ 預設參數符合經典等距光影比例
- ✅ 完整的 JSDoc 註解，明確標註光源方向
- ✅ 可擴展設計，易於新增更多等距效果函數

**第 1 次迭代評分**：9/10

### 任務 #3：傳送門深度化

**實作位置**：`/js/map.js` 行 1264-1315（drawPortalFull 函數）

**實作內容**：

#### 3.1 設計概念

**凹陷坑洞 + 三層深度漩渦**：
- 四邊等距邊緣產生「地面凹陷」效果
- 三層漩渦（60%/80%/100% 縮放）產生深度遞進
- 地面光暈 + 漩渦旋轉雙重動畫

#### 3.2 核心實作

**1. 地面凹陷邊緣**（四邊等距光影）
```javascript
const edgeColor = '#4a4236'; // 地板色
// 上邊緣（最亮，頂面光照）
PA.rect(ctx, x, y, 32, 2, ISO.topLight(edgeColor));
// 左邊緣（最暗，側面陰影）
PA.rect(ctx, x, y, 2, 32, ISO.sideDark(edgeColor));
// 右邊緣（中亮）
PA.rect(ctx, x + 30, y, 2, 32, PA.lighten(edgeColor, 10));
// 下邊緣（較暗，深度遞減）
PA.rect(ctx, x, y + 30, 32, 2, PA.darken(edgeColor, 20));
```

**2. 三層深度漩渦**（scale + offset + alpha）
```javascript
// 深層（最小、最暗、最深）
ctx.globalAlpha = 0.4;
ctx.translate(0, 2); // 向下偏移 2px
this.drawSwirlPattern(ctx, colorScheme, 0.6); // 縮放 60%

// 中層
ctx.globalAlpha = 0.7;
ctx.translate(0, 1); // 向下偏移 1px
this.drawSwirlPattern(ctx, colorScheme, 0.8); // 縮放 80%

// 淺層（最大、最亮、表面）
this.drawSwirlPattern(ctx, colorScheme, 1.0); // 原始大小
```

**3. 修改 drawSwirlPattern**（支援 scale 參數）
```javascript
drawSwirlPattern(ctx, colorScheme, scale = 1.0) {
  // 螺旋臂繪製時乘以 scale
  const px = Math.cos(armAngle) * r * scale;
  const py = Math.sin(armAngle) * r * scale;
}
```

#### 3.3 技術亮點

- ✅ **四邊等距邊緣**：topLight/sideDark 分配合理，產生凹陷感
- ✅ **三層深度系統**：透過 scale(縮放)、offset(偏移)、alpha(透明度) 模擬立體深度
- ✅ **Canvas 變換巧妙**：使用 `ctx.save()/restore()` 嵌套管理多層狀態
- ✅ **動畫流暢**：旋轉（0.5 秒/圈）+ 光暈脈動（1 秒週期）雙重動畫
- ✅ **可復用設計**：drawSwirlPattern 支援 scale 參數，可用於其他旋轉效果

**第 1 次迭代評分**：9.5/10
