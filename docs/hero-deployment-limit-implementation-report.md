## 📋 功能概述

實作了英雄部署限制系統，確保每個英雄類型只能部署一隻，增加遊戲策略深度。

### 核心功能
- ✅ 限制每個英雄類型只能部署一隻（水法師/火法師）
- ✅ 嘗試重複部署時顯示錯誤訊息
- ✅ 已部署的英雄按鈕顯示為 disabled 狀態
- ✅ 回收英雄後按鈕恢復可用狀態

const sameTypeExists = this.active.some(h =>
  h.type.id === heroTypeId && h.alive

  if (DK.ErrorHandler) {

4. 如果不存在，繼續執行部署流程

## 🔍 實作細節說明

### 1. 檢查邏輯的精確性
```javascript
const sameTypeExists = this.active.some(h =>
  h.type.id === heroTypeId && h.alive
);
```

**關鍵點**：
- 使用 `h.type.id === heroTypeId` 而非 `h.type === typeDef`
  - 原因：物件比較可能失敗，ID 比較更可靠
- 檢查 `h.alive` 狀態
  - 原因：已死亡的英雄不應阻止部署

### 2. UI 狀態更新時機
按鈕狀態在以下時機自動更新：
1. 每次渲染時（`getButtonState()` 被調用）
2. 部署英雄後（`deploy()` 返回後，UI 重繪）
3. 回收英雄後（`recall()` 執行後，UI 重繪）

**無需手動觸發更新**，遊戲循環會自動處理。

### 3. 錯誤處理流程
```
部署嘗試
  ↓
檢查同類型是否已部署
  ↓
[是] → showError('hero_already_deployed') → return false
  ↓
[否] → 繼續檢查位置、金幣等
```
