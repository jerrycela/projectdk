# ProjectDK - 英雄角色重新設計完成報告

**日期**：2026-02-14
**類型**：視覺升級 - 角色重新設計

## 📋 任務概述

重新設計遊戲中的兩位英雄角色（利維坦水法師、巴爾火法師），汲取《歧路旅人》的精緻像素藝術風格，同時保持 ProjectDK 現有的 DW3 冷色調美學。

### 設計目標
- ✅ 增加服飾、配飾、武器細節
- ✅ 強化角色辨識度和職業特色
- ✅ 保持 12-14px 核心尺寸的可讀性
- ✅ 融合兩種風格而不衝突

## 🌊 利維坦（Leviathan）- 深海女巫

### 設計概念
從「海洋女神」轉型為「深海女巫」，強化神秘、優雅的水元素特質。

### 視覺變更

#### 1. 髮色改變（金色 → 銀藍色）
**原設計**：金色長髮（與火法師相同）
**新設計**：銀藍色長髮（更符合水元素）

**新增色彩**：
- `hairDark: #3a5a8a` - 深藍灰（髮根）
- `hairMid: #6a8aaa` - 中度銀藍
- `hairLight: #8aaacc` - 淺銀藍
- `hairTip: #aaccee` - 髮梢高光

#### 2. 半透明海藍披風
**新增元素**：背景層次的外披
**技術實作**：
```javascript
ctx.save();
ctx.globalAlpha = 0.6;
PA.rect(ctx, cloakX - 6, y - 2, 13, 6, C.HERO_WATER_CLOAK);
// ... 披風繪製
ctx.restore();
```

**動畫**：披風飄逸動畫（`cloakSwayX`），行走時搖擺幅度 > 裙擺

**新增色彩**：
- `cloak: #1a3a6a` - 深海藍
- `cloakDark: #0e2a4a` - 陰影
- `cloakEdge: #4488cc` - 邊緣高光

#### 3. 裙擺升級
**新增元素**：
- 水紋圖案（簡化波浪紋）
- 珍珠邊飾（裙擺點綴）

**新增色彩**：
- `wavePattern: #2a4a7a` - 水紋深藍

#### 4. V字領上衣 + 胸針
**原設計**：簡單上衣
**新設計**：V字領 + 銀色邊飾 + 水晶胸針

#### 5. 銀色冰冠（5尖設計）
**原設計**：金冠 3尖
**新設計**：銀冠 5尖 + 海藍寶石

**新增色彩**：
- `crown: #c0d0e8` - 銀色冰冠
- `crownGem: #4488dd` - 海藍寶石

#### 6. 升級三叉戟
**原設計**：簡單三叉戟
**新設計**：海螺形水晶設計 + 金環裝飾

**特效**：攻擊時水晶折射效果

#### 7. 其他細節
- 眼影（`eyeShadow: #6688aa`）
- 銀色手鐲
- 冷色調嘴唇（`#cc7788`）
- 待機時漂浮水珠粒子

## 🔥 巴爾（Baal）- 火焰女皇

### 設計概念
從「火焰女神」升級為「火焰女皇」，強化戰鬥、力量感的火元素特質。

### 視覺變更

#### 1. 火焰形高馬尾
**原設計**：金色長髮（與水法師相同）
**新設計**：向上飛揚的高馬尾，尾端火焰特效

**技術實作**：
- 基礎馬尾（`ponytailSwayX`, `ponytailSwayY`）
- 向上延伸（y - 15 ~ y - 20）
- 火焰尾端動畫

**新增色彩**：
- `hairTip: #ffaa44` - 火焰橙
- `flameTip: #ffdd66` - 火焰亮黃

#### 2. 金色肩甲護肩
**新增元素**：3×2 px 鎧甲板（左右各一）

**技術實作**：
```javascript
// 左肩甲
PA.rect(ctx, x - 5, y - 5, 3, 2, C.HERO_FIRE_ARMOR);
PA.pixel(ctx, x - 5, y - 5, C.HERO_FIRE_ARMOR_LIGHT); // 高光
PA.pixel(ctx, x - 3, y - 4, C.HERO_FIRE_ARMOR_DARK); // 陰影
```

**新增色彩**：
- `armor: #8a6a40` - 金色鎧甲
- `armorLight: #ccaa60` - 高光
- `armorDark: #5a4a20` - 陰影

#### 3. 戰鬥短披（腰長）
**原設計**：無披風
**新設計**：只到腰部的短披（戰鬥風格）

**新增色彩**：
- `cloak: #5a2030` - 深紅
- `cloakDark: #3a1020` - 陰影
- `cloakEdge: #8a4060` - 邊緣

#### 4. 火焰圖騰裙擺
**新增元素**：
- 火焰圖騰紋樣（簡化火符號）
- 金色邊飾（動畫閃爍）

**新增色彩**：
- `emblem: #ff6622` - 火焰紋章

#### 5. 金屬鎖鏈腰帶
**原設計**：簡單金帶
**新設計**：金屬鎖鏈 + 火焰寶石中心

**新增色彩**：
- `chainGold: #ddaa30` - 鏈金色

#### 6. 火焰皇冠（5尖設計）
**原設計**：金冠 3尖
**新設計**：金冠 5尖 + 跳動火焰

**新增色彩**：
- `crownDark: #cc8800` - 暗金色

#### 7. 鳳凰法杖
**原設計**：簡單火焰法杖
**新設計**：鳳凰展翅設計

**技術實作**：
- 鳳凰頭/喙（中央）
- 左右翅膀（攻擊時展開更寬）
- 火焰冠羽（動畫閃爍）
- 尾羽（攻擊時顯示）

**攻擊特效**：
```javascript
if (attacking) {
  // 翅膀展開更寬
  PA.pixel(ctx, weaponX + 5, y - 14, C.HERO_FIRE_HAIR_TIP);
  PA.pixel(ctx, weaponX + 11, y - 14, C.HERO_FIRE_HAIR_TIP);
  // 尾羽出現
  PA.pixel(ctx, weaponX + 7, y - 11, C.HERO_FIRE_CROWN_DARK);
  PA.pixel(ctx, weaponX + 9, y - 11, C.HERO_FIRE_CROWN_DARK);
}
```

#### 8. 其他細節
- 深色手套
- 待機時舞動火焰粒子
- 火焰項鏈（閃爍動畫）
