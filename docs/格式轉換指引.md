# ProjectDK 企劃書格式轉換指引

## 方案 A：使用 Pandoc（推薦，最快速）

### 安裝 Pandoc

```bash
# macOS (使用 Homebrew)
brew install pandoc

# 或下載安裝檔
# https://pandoc.org/installing.html
```

### 轉換為 DOC 格式

```bash
cd /Users/admin/Downloads/遊戲專案/projectdk/projectdk/docs

# 轉換為 DOCX
pandoc ProjectDK-遊戲企劃書.md -o ProjectDK-遊戲企劃書.docx \
  --from=markdown \
  --to=docx \
  --reference-doc=template.docx  # (可選) 使用自訂樣式模板
```

### 轉換為 PPT 格式

```bash
# 方案 1: 使用 Pandoc 生成基礎 PPTX（較陽春）
pandoc ProjectDK-遊戲企劃書.md -o ProjectDK-遊戲企劃書.pptx \
  --from=markdown \
  --to=pptx \
  --slide-level=2  # ## 標題 = 新投影片

# 方案 2: 先轉 DOCX，再用 PowerPoint 手動調整（較精緻）
# 1. 先生成 DOCX（如上）
# 2. 開啟 PowerPoint，匯入 DOCX
# 3. 手動調整版面、加入圖表
```

## 方案 B：使用 Google Docs / Microsoft Word（線上工具）

### 步驟 1：上傳 Markdown 到 Google Docs

1. 開啟 [Google Docs](https://docs.google.com)
2. 新增文件
3. 複製 `ProjectDK-遊戲企劃書.md` 內容
4. 貼上到 Google Docs
5. 手動調整格式（標題、表格、清單）

### 步驟 2：匯出為 DOC

- Google Docs → 檔案 → 下載 → Microsoft Word (.docx)

### 步驟 3：匯入到 Google Slides / PowerPoint

1. 開啟 [Google Slides](https://slides.google.com)
2. 新增簡報
3. 匯入大綱（從 Google Docs 複製章節標題）
4. 手動調整版面、加入圖表

## 方案 C：使用 Python 腳本（自動化，需安裝套件）

### 安裝必要套件

```bash
pip3 install python-docx markdown python-pptx
```

### 執行轉換腳本

```bash
# 轉換為 DOCX
python3 convert_to_docx.py

# 轉換為 PPTX
python3 convert_to_pptx.py
```

*(腳本檔案需另外撰寫，或使用 chatgpt-cli 等工具生成)*

## 方案 D：使用線上轉換工具（最簡單，但功能有限）

### 推薦工具

1. **CloudConvert** - https://cloudconvert.com/md-to-docx
   - 上傳 `ProjectDK-遊戲企劃書.md`
   - 選擇輸出格式：DOCX
   - 下載轉換後檔案

2. **Dillinger** - https://dillinger.io
   - 貼上 Markdown 內容
   - 匯出為 HTML
   - 用 Word 開啟 HTML 並另存為 DOCX

3. **Markdown to PDF** - https://md2pdf.netlify.app
   - 轉為 PDF 後用 Adobe Acrobat 轉 DOCX

## 推薦流程（最佳品質）

### DOC 格式

1. 使用 **Pandoc** 快速生成 DOCX
2. 用 **Microsoft Word** 或 **Google Docs** 開啟
3. 手動調整：
   - 封面設計（加入 Logo、視覺元素）
   - 表格美化（顏色、對齊）
   - 章節分頁（每個大章節分頁）
   - 頁碼、目錄

### PPT 格式

1. 開啟 **PowerPoint** 或 **Google Slides**
2. 依據企劃書章節手動製作投影片：
   - **封面**：遊戲名稱、Logo、標語
   - **執行摘要**：核心亮點表格
   - **遊戲概述**：世界觀、核心玩法
   - **元素反應系統**：3 種反應的圖示說明
   - **光環進化**：進化流程圖
   - **財務預測**：收入 vs 成本圖表
   - **時間表**：甘特圖或時間軸
   - **行銷策略**：渠道分佈圖
   - **結論**：投資亮點 + 行動呼籲
3. 建議投影片數量：20-30 頁（精簡版）

## 注意事項

### Markdown 轉檔常見問題

| 問題 | 解決方案 |
|------|---------|
| **表格跑版** | 手動調整欄寬、字體大小 |
| **程式碼區塊** | 轉為引言區塊或刪除 |
| **特殊字元** | 檢查編碼（UTF-8），手動修正 |
| **圖片缺失** | 企劃書中沒有圖片，需手動加入 |

### PPT 製作建議

| 要素 | 建議 |
|------|------|
| **字體** | Sans-serif（Arial、Helvetica）清晰易讀 |
| **配色** | 暗色系（配合地牢主題），強調色用金色/藍色 |
| **圖表** | 使用 PowerPoint 內建圖表工具（長條圖、圓餅圖） |
| **動畫** | 少用，避免分散注意力 |
| **圖片** | 加入遊戲截圖（可用手機截圖或螢幕錄影） |
