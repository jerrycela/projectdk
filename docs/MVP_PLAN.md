### 迭代 3/10 - 地圖與路徑格式確定

**決策**：
- 地圖定義：純程式碼（字串陣列）✓
- 美術資源：純色方塊 ✓
- 箭塔射擊：瞬間命中 ✓
- 暫停功能：MVP 不做 ✓

**地圖格式定義**：
```javascript
const MAP_TILES = {
  '#': 'wall',      // 牆壁 - 可放牆壁陷阱
  '.': 'path',      // 路徑 - 敵人行走
  '_': 'ground',    // 空地 - 可放地面陷阱
  'S': 'spawn',     // 敵人出生點
  'E': 'exit'       // 終點（基地）
};
```

**路徑系統**：
- 使用 waypoints 陣列定義路徑
- 敵人依序走過每個 waypoint
- 不需要 A* 演算法（單一路徑）

### 迭代 4/10 - 陷阱放置規則

**地面陷阱（尖刺）**：
- 只能放在 `_` (ground) 格子
- 敵人踩上去時觸發傷害
- 每格只能放一個陷阱

**牆壁陷阱（箭塔）**：
- 只能放在 `#` (wall) 格子
- 自動攻擊範圍內的敵人
- 射擊方向：朝向最近的路徑

**放置流程**：
1. 玩家點擊 UI 選擇陷阱類型
2. 地圖上顯示可放置區域（高亮）
3. 玩家點擊有效格子放置
4. 扣除金幣

### 迭代 6/10 - 敵人行為

**移動邏輯**：
1. 從 spawn 點生成
2. 沿 waypoints 移動
3. 到達終點 → 基地扣血 → 敵人消失
4. HP 歸零 → 播放死亡 → 給金幣 → 消失

**視覺**：
- 敵人：紅色圓形（半徑 12px）
- 血條：敵人上方綠色條

### 迭代 7/10 - 波次系統

```javascript
const WAVES = [
  { enemies: 5, delay: 1000 },   // 波次1：5隻，間隔1秒
  { enemies: 8, delay: 800 },    // 波次2：8隻，間隔0.8秒
  { enemies: 12, delay: 600 }    // 波次3：12隻，間隔0.6秒
];
```

**流程**：
1. 玩家點「開始」
2. 生成該波敵人
3. 全部清完 → 顯示「下一波」按鈕
4. 全部波次完成 → 勝利
