# ProjectDK - 2×2 傳送門漩渦系統實作

## 概述

完成 Phase 1.1 視覺增強：將傳送門從小型靜態圖案（6×8px）升級為 2×2 大型動畫漩渦（32×32px），包含旋轉螺旋、脈動光暈、環繞粒子效果。靈感來源於 Dungeon Keeper 和魔獸爭霸 3 的傳送門設計。

## 核心功能

### 1. 錨點檢測系統
```javascript
isPortalAnchor(col, row) {
  // 檢查左上角格子及其右、下、右下格子是否都是相同傳送門類型
  // 確保 2×2 佈局完整性
}
```

### 2. 漩渦動畫渲染
- **旋轉螺旋**：4 條螺旋臂，每條獨立旋轉
- **脈動光暈**：徑向漸變，1 秒週期 (alpha 0.4-0.6)
- **能量環**：半透明圓環，同步脈動 (alpha 0.3-0.7)
- **環繞粒子**：8 個光點，圓形軌道運動，獨立速度變化

### 3. 顏色配置
- **入口傳送門（綠色）**：
  - 深色：`#226622`
  - 亮色：`#44aa44`
  - 螢光：`#66ff66`

- **出口傳送門（紅色）**：
  - 深色：`#662222`
  - 亮色：`#aa4444`
  - 螢光：`#ff6666`

### 4. 性能優化
- 2×2 傳送門直接繪製（動畫效果）
- 單格傳送門使用靜態快取（向後兼容）
- 其他地磚保持快取機制

## 技術實作

### 修改檔案
- **js/map.js** (+170 行)
  - `isPortalAnchor()` - 錨點檢測
  - `drawSwirlPattern()` - 漩渦圖案
  - `drawPortalFull()` - 完整 2×2 渲染
  - `drawEntranceTile()` - 入口傳送門（支持 2×2）
  - `drawExitTile()` - 出口傳送門（支持 2×2）
  - `render()` - 渲染邏輯（動態/靜態分流）

### 動畫時間軸
```javascript
const time = (Date.now() / 1000) % 3600; // 秒
- 漩渦旋轉：time * Math.PI (0.5 秒/圈)
- 脈動週期：sin(time * Math.PI * 2) (1 秒週期)
- 粒子運動：time * 2 * speed (獨立速度)
```
