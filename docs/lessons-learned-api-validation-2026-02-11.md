**日期**：2026-02-11

---

## 事件回顧

### 問題描述
用戶報告進入遊戲後，**所有陷阱/圖標按鈕完全是黑色**，無法點擊選擇。連關卡編輯器的圖標也變黑了。

### 根本原因
```javascript
// main.js:357, 401 呼叫了不存在的方法
ctx.font = DK.FONTS.normal(14);  // ❌ TypeError!

// 實際 DK.FONTS 定義
DK.FONTS = {
  body(size) { ... },  // ✅ 正確的方法
  // ❌ 沒有 normal() 方法！
}
```

**連鎖效應**：TypeError → Canvas 渲染中斷 → 所有 UI 黑屏

---

## 關鍵教訓

### 1. 語法檢查 ≠ API 存在性檢查
- `node -c` 只檢查語法，不檢查 API 是否存在
- 需要執行期 API 驗證

### 2. QA 測試必須清除快取
- 使用 URL 版本號：`<script src="js/main.js?v=20260211">`
- 測試前 Hard Refresh

### 3. 視覺回歸測試的必要性
- 使用 Playwright 截圖比對
- 自動化測試無法捕獲視覺錯誤

### 4. API 命名一致性
- 避免 `DK.ENEMIES` vs `DK.ENEMY_TYPES` 的混淆
- 統一命名規範
